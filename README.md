# Commodious GitDock

**Drop it. Ship it. Sync it.**

A local, drag-and-drop GitHub publisher with linked projects and Smart Sync, by **Jordie Cruz · Commodious Works LLC**.

GitDock v1.2 supports project-folder and ZIP uploads, official GitHub sign-in, manual syncing, change previews and optional Auto-Sync when files are saved in Cursor or another editor.

**Windows:** Download the installer from the [Releases](https://github.com/Cruz4/Commodious-GitDock/releases) page when available. Installation may prompt to add Node.js, Git and GitHub CLI if missing. The native Windows launcher is unsigned.

**Security:** Keep private credentials and `.env` files out of public repositories. GitDock has exclusions and basic secret detection, but they cannot detect every secret.
